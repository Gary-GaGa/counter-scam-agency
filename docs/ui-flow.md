# UI Flow（文字版）

本文件描述 MVP 階段的文字冒險 UI 流程，作為 CLI 或簡易介面原型的基礎。

## 1. 流程概覽
1. 案件列表 / 選擇任務
2. 案件簡介 / 目標
3. 文字節點閱讀
4. 選項選擇
5. 蒐證 / 狀態更新
6. 結案判定
7. 結算回饋（聲望、紀錄）
8. 成長與解鎖（模組 / 技能）

## 2. 詳細步驟
### 2.1 案件選擇
- 顯示可接案件清單（名稱、詐騙類型、難度）
- 使用者選擇任務後進入簡介

### 2.2 案件簡介
- 顯示任務標題、簡介、目標提示
- 顯示預估難度與聲望權重
- 使用者確認後開始調查

### 2.3 節點閱讀
- 顯示節點標題與敘事內容
- 顯示可選選項清單（依序編號）

### 2.4 選項選擇
- 使用者輸入選項編號
- 系統套用結果：
  - 變更到下一節點
  - 蒐證（若選項附帶證據）
  - 判定是否進入結案節點

### 2.5 蒐證 / 狀態更新
- 顯示新取得的證據摘要
- 顯示目前已蒐證列表（可簡化為計數）

### 2.6 結案判定
- 若達成結案節點：
  - 成功：顯示結案敘述與總結
  - 失敗：顯示失敗原因與總結

### 2.7 結算回饋
- 顯示任務結果（成功/失敗）
- 顯示聲望變化（失敗為 0）
- 顯示本次新增證據清單

### 2.8 成長與解鎖
- 顯示累計聲望與解鎖提醒
- 返回案件列表或結束遊戲

## 3. 最小 UI 元素（CLI）
- 標題 / 分隔線
- 主要敘事區塊
- 選項清單
- 系統提示（輸入錯誤 / 狀態更新）
- 結算摘要區塊

## 4. 與 CA + DDD 的對應
- Domain：Mission / NarrativeNode / NarrativeOption / Evidence
- Usecase：StartInvestigation / AdvanceNode / CompleteInvestigation
- Interface：CLI Adapter 負責輸入輸出與流程串接
