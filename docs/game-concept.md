# Counter Scam Agency — 遊戲企劃草案

## 1. 遊戲定位
- **題材**：防範詐騙的角色扮演（RPG）
- **玩家身分**：新晉「反詐情報官」，帶著 AI 夥伴在城市中協助市民識破詐術。
- **體驗目標**：
  1. 在案件推理中學習防詐知識。
  2. 享受劇情、角色養成與工具解鎖的成就感。
  3. 建立可長期擴充的案件/圖鑑系統。

## 2. 核心循環
1. 接收案件或市民請求。
2. 文字冒險節點：閱讀節點敘事並選擇行動（不使用條件分支）。
3. 調查：蒐集對話、帳務、社群、設備等線索。
4. 判讀：辨識詐術、估計危險程度。
5. 處置：指導 NPC、阻止匯款、釣魚回擊或聯繫警方。
6. 回饋：結算聲望、情報素材，更新「詐術圖鑑」。
7. 成長：以累計聲望解鎖新工具與模組。

## 3. 系統支柱
| 系統 | 說明 | 範例 |
| --- | --- | --- |
| 案件調查 | 文字冒險節點敘事，玩家透過選項推進案件 | 假客服、投資詐騙、AI 語音詐術 |
| 技能養成 | 四大技能樹：社交洞察、金融偵測、數據取證、心理韌性 | 解鎖語音比對、交易異常分析、心理疏導 |
| 情報擴散 | 破案後撰寫警示公報或開直播分享，提升城市安全度 | 城市安全度越高，詐騙成功率越低 |
| 圖鑑收集 | 每種詐術會記錄徵兆、危害與防範步驟 | 可供玩家/AI 夥伴在後續案件中引用 |

## 4. 章節示例
1. **新手訓練**：假冒客服／OTP 詐騙，教授基本辨識。
2. **市區巡防**：網拍詐騙、投資群組，需要多線索交叉。
3. **情感攻防**：愛情詐騙、親友冒名，著重情緒與語音分析。
4. **高科技對決**：深偽影音、AI 語音，加入迷你分析遊戲。
5. **跨國詐團**：建立關係圖譜與多 NPC 協調任務。

## 5. AI 夥伴系統 (AI Partner System)
AI 不僅是導航員，更是玩家的「外掛裝備」與「情感投射對象」。

### 5.1 模組化裝備 (Modular Loadout)
玩家可為 AI 安裝不同模組來強化核心數值與小遊戲表現：
*   **語音分析模組 (Voice Analyzer)**：
    *   **效果**：在「矛盾擊破」中自動標記語氣異常的關鍵字。
    *   **對應數值**：邏輯 (Logic)
*   **金流追蹤模組 (Crypto Tracer)**：
    *   **效果**：在「訊號追蹤」中自動鎖定正確路徑。
    *   **對應數值**：技術 (Tech)
*   **情感模擬模組 (Empathy Engine)**：
    *   **效果**：在「談判牌局」中預測對方下一張牌的情緒屬性。
    *   **對應數值**：交涉 (Charisma)
*   **防火牆模組 (Mental Firewall)**：
    *   **效果**：減少調查失敗時的 SAN 值扣除。
    *   **對應數值**：韌性 (Resilience)

### 5.2 主動技能 (Active Skills)
在關鍵時刻可呼叫 AI 釋放技能（有冷卻時間）：
*   **深層掃描 (Deep Scan)**：直接顯示當前畫面上的一個隱藏線索。
*   **時間凍結 (Time Freeze)**：在限時操作中暫停時間 5 秒。
*   **強制阻斷 (Force Block)**：在即時攻防中，直接消除一個危險訊號。

### 5.3 性格演化 (Personality Evolution)
AI 的性格會隨玩家的辦案風格而改變：
*   **理性型 (Logic-driven)**：
    *   **觸發**：常選擇「直接揭穿」、「報警處理」。
    *   **特質**：冷靜高效，但缺乏同理心。
*   **感性型 (Empathy-driven)**：
    *   **觸發**：常選擇「安撫受害者」、「了解背後故事」。
    *   **特質**：溫柔主動，但在緊急狀況可能猶豫。

## 6. 指標與難度
- **聲望**：代表玩家可信度，來自任務累計加權，失敗不給聲望。
- **城市安全度**：越高則詐騙事件成功率下降，但詐團會升級手法。
- **壓力值**：處理大量案件會累積壓力，需要休息/活動降低。

## 7. MVP 建議
1. 兩種案件：假客服、投資社群。
2. 文字冒險流程：節點敘事 + 選項 + 結案回饋。
3. 成功/失敗結算：成功才累計聲望，解鎖模組與下一案件。
4. CLI 或簡易 UI 原型，先驗證文字冒險流程與回饋循環。

## 8. 擴充特色 (Extended Features)
| 特色 | 說明 | 玩法機制 |
| --- | --- | --- |
| **受害者心理側寫** | 分析受害者心理弱點（貪婪、恐懼、孤獨） | 針對不同心理狀態選擇安撫或數據打臉策略 |
| **反向腳本模擬** | 扮演詐騙集團，重組話術 | 從卡牌中組合詐騙劇本，系統指出邏輯破綻 |
| **道德抉擇** | 處理非黑即白的灰度案件 | 選擇追回金錢但犧牲其他價值，或反之，影響結局 |
| **數位防禦基地** | 具象化的資安建設 | 升級基地設施（如防火牆、保險庫）對應現實資安設定 |
| **社群共創案件** | 玩家投稿真實詐騙案例 | 審核後轉化為每日懸賞案件，保持內容時效性 |
| **即時攻防** | 阻止轉帳的緊急時刻 | 透過打字或連線小遊戲中斷交易訊號 |

## 9. 遊戲性與成長循環 (Gameplay & Progression Loop)
核心體驗建立在「小遊戲挑戰 → 角色數值成長 → 解鎖更難案件」的循環上。
MVP 階段以文字冒險為主，小遊戲為後續擴充。

### 9.1 角色基礎數值 (Core Stats)
所有小遊戲的表現都會回饋到以下四項數值，數值提升可解鎖對應能力：
1.  **邏輯 (Logic)**：
    *   **影響**：看穿謊言的機率、推理線索的準確度。
    *   **提升方式**：完成「矛盾擊破」小遊戲。
2.  **技術 (Tech)**：
    *   **影響**：使用高科技工具的成功率、追蹤金流的速度。
    *   **提升方式**：完成「訊號追蹤」小遊戲。
3.  **交涉 (Charisma)**：
    *   **影響**：NPC 信任度、說服受害者停止匯款的效果。
    *   **提升方式**：完成「談判牌局」小遊戲。
4.  **韌性 (Resilience)**：
    *   **影響**：SAN 值上限、面對負面情緒的抗壓性。
    *   **提升方式**：完成「心靈調適」小遊戲。

### 9.2 小遊戲機制 (Mini-games)
| 小遊戲 | 對應數值 | 玩法描述 | 參考原型 |
| :--- | :--- | :--- | :--- |
| **矛盾擊破** | 邏輯 | 畫面上流過證詞，玩家需發射正確的「證據子彈」擊碎謊言。 | 逆轉裁判、彈幕遊戲 |
| **訊號追蹤** | 技術 | 在限時內旋轉節點接通管線，或輸入代碼攔截封包。 | Pipe Mania, Hacker Tycoon |
| **談判牌局** | 交涉 | 出牌（如「同理心」、「數據佐證」）來削減對方的「固執值」。 | Slay the Spire (簡化版) |
| **心靈調適** | 韌性 | 簡單的節奏點擊或整理房間遊戲，回復 SAN 值。 | Unpacking, Rhythm Heaven |
